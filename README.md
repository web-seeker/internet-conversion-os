## 它是什么？

互联网转化OS 是一个**系统化的 AI 转化专家**，不是一个只会写文案的工具。

它将互联网转化拆解为 **8 个相互关联的模块**，覆盖从「用户第一次看到你」到「用户主动推荐你」的完整链路。无论你是做电商、SaaS、知识付费、个人品牌还是 B2B，它都能给出**针对你行业的、具体可执行的转化方案**。

**一句话：它帮你把价值变成收入。**

## 为什么选它而不是其他 Skill？

### 差异化竞争力

**1. 不是单点工具，是操作系统**

市面上大多数营销类 Skill 只做一件事——写文案、起标题、做 SEO。互联网转化OS 是**唯一一个覆盖完整转化链路的系统化 Skill**。8 个模块环环相扣，从价值定义到增长飞轮，形成完整闭环。

**2. 不是给建议，是给方案**

它不会告诉你"你应该提升信任"这种废话。它会告诉你：
- 信任度评分：当前 4/10
- 短板：缺少案例证明和第三方背书
- 本周行动：收集 3 个用户案例，联系 1 个行业 KOL
- 素材清单：案例模板、评价截图规范、数据展示格式

**3. 不是一次性使用，是持续运营系统**

内置使用节奏：每周诊断、每半月内容策划、每月旅程优化、每季度全链路审计。每次使用都基于上次输出迭代，越用越精准。

**4. 行业自适应**

自动识别 7 大行业（电商/SaaS/教育/B2B/内容创作/个人品牌/本地服务），调整分析框架和重点关注模块。不是一套方案打天下。

**5. 新手零门槛**

4 个问题快速启动，推荐执行路径（诊断→价值→注意力→行动→旅程），不需要你懂营销术语就能上手。

### 与其他常见 Skill 的对比

| 维度 | 普通文案 Skill | SEO Skill | 营销顾问 Skill | **互联网转化OS** |
|------|-------------|----------|-------------|---------------|
| 覆盖范围 | 单点（文案） | 单点（SEO） | 咨询建议 | **全链路 8 模块** |
| 输出质量 | 文案文本 | 关键词列表 | 框架建议 | **具体可执行方案** |
| 行业适配 | 通用 | 通用 | 需要你描述 | **自动识别+适配** |
| 持续使用 | 用完即走 | 用完即走 | 用完即走 | **内置使用节奏，越用越准** |
| 新手友好 | 需要你写 prompt | 需要你懂 SEO | 需要你懂营销 | **4 个问题即可启动** |
| 诊断能力 | 无 | 无 | 有限 | **五层诊断模型，逐层排查** |

## 快速开始

### 安装

将 `internet-conversion-os/` 目录复制到你的 AI 工作区项目的技能目录下（具体路径取决于你使用的 AI 工具平台）。

### 第一次使用

只需告诉它：

> "我的产品是 [你的产品]，目标用户是 [你的用户]，目前 [描述你的问题]"

或者更简单地：

> "帮我诊断转化问题"

它会通过 4 个问题快速了解你的情况，然后给出针对性方案。

### 推荐使用路径（新手）

```
诊断（M7）→ 定义价值（M1）→ 获取注意力（M3）→ 触发行动（M5）→ 设计旅程（M6）
```

先找到问题，再从根源解决。

## 使用场景示例

### 场景 1：电商转化率低

> "我的淘宝店每天 500 访客，但只有 10 单，转化率 2%，怎么提升？"

它会：诊断停留→信任→行动各环节 → 优化主图和详情页价值包装 → 设计 CTA 和促销策略 → 给出具体改版方案。

### 场景 2：内容创作者变现

> "我有 5 万抖音粉丝，但不知道怎么变现"

它会：分析你的价值五维 → 定位你的核心价值主张 → 设计从粉丝到付费的转化路径 → 规划内容策略和信任构建方案。

### 场景 3：SaaS 试用转付费

> "我们 SaaS 产品月注册 1000 人，但付费转化只有 3%"

它会：诊断试用体验的信任缺口 → 设计用户旅程中的关键触点 → 优化行动触发机制 → 给出提升到 8% 的具体方案。

### 场景 4：新产品上线

> "我要上线一个在线课程，教 Python 入门"

它会：从价值定义开始 → 包装课程价值 → 设计注意力策略 → 规划信任素材 → 设计预售到正价的转化路径 → 输出完整上线方案。

## 技术信息

- **类型**：AI Agent Skill（自主运行 SubAgent）
- **上下文**：支持同类型对话上下文感知（`same_type`），可基于前次输出迭代优化
- **触发方式**：自动识别营销/转化/增长相关需求，也可手动指定模块
- **输出格式**：结构化方案（文字+表格+可视化描述），支持全链路文档输出
- **兼容平台**：支持所有主流 AI 工具平台（ClawHub、TRAE、CodeBuddy 等）
