# 互联网转化OS（Internet Conversion OS）

> 从价值定义到增长飞轮的全链路转化框架

将价值转化为用户行为：停留 → 关注 → 点击 → 咨询 → 购买 → 订阅 → 复购 → 传播

## 核心公式

**收入 = 价值 × 注意力 × 信任 × 转化率**

## 八大模块

| 模块 | 核心问题 | 输出 |
|------|---------|------|
| 价值系统 | 你到底在卖什么？ | 价值地图 |
| 价值包装 | 如何让价值被看见？ | 价值呈现方案 |
| 注意力获取 | 如何获得停留？ | 注意力策略 |
| 信任构建 | 如何让用户相信？ | 信任增长方案 |
| 行动触发 | 如何让用户行动？ | 行动触发方案 |
| 用户旅程 | 用户如何一步步成交？ | 用户旅程地图 |
| 增长飞轮 | 如何形成持续增长？ | 增长飞轮模型 |
| 转化诊断 | 问题出在哪里？ | 诊断报告+优化建议 |

## 使用方式

将 `.trae/skills/internet-conversion-os/` 目录复制到你的 TRAE 工作区项目的 `.trae/skills/` 下，即可激活该技能。

## 技能触发

当你需要以下任何帮助时，该技能会自动激活：
- 营销策略制定
- 转化率优化
- 用户增长方案
- 内容策划
- 商业变现设计
- 产品价值定位
- 信任构建策略
- 用户旅程设计
